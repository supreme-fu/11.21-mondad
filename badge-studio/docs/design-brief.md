# Do Something 生活徽章收藏室 · 设计简报

## 一句话概念

把生活中的小事做成可以拿在手里转动、端详的纪念物，而不是分数、排名或奖励承诺。

## 交付清单

- [ ] 阅读、做饭、旅行、见到想见的人：4 枚独立造型与材质的 3D 徽章。
- [ ] 合约基础金属徽章：可编辑的演示合约编号，真实部署后由用户替换。
- [ ] 10 次铜章、50 次银章、100 次金章；100 次同级提供白金与钻石材质变体，共 9 枚展示对象。
- [ ] 鼠标拖动旋转、移动视差、悬停倾斜、点击聚焦、上一枚／下一枚、自动旋转与复位。
- [ ] Play 首屏直接显示中文操作按钮、快捷键和用途提示。
- [ ] 拉丝金属、镜面金属、彩色珐琅、珍珠、烤漆与折射晶体可明确区分。
- [ ] 每枚模型可独立选择、编辑材质；场景暴露合约编号、旋转速度、展示尺寸。
- [ ] 输出 9 个 GLB、总览与单徽章 PNG、源项目；静态 GLB 不包含交互逻辑。
- [ ] 真实合约尚未部署，界面与素材明确标注 DEMO，不虚构真实合约编号或里程碑达成。

## 参考特征 → 制作决策

| 参考特征 | 本作品决策 |
| --- | --- |
| Three.js PBR 金属依赖环境反射 | 使用 Poly Haven Studio Small 09 CC0 1k HDRI，environmentIntensity 0.85。 |
| 拉丝金属 roughness 约 0.3–0.45 | 基础合约章 roughness 0.36，叠加程序化细微粗糙度纹理。 |
| 镜面金属 roughness 约 0.05–0.15 | 银、金、白金外圈 roughness 0.12–0.18，保留清晰棚灯反射。 |
| 釉面陶瓷 clearcoat 0.5–1 | 阅读与相见徽章使用 clearcoat 0.85、roughness 0.2 的彩色珐琅。 |
| 珍珠有柔和有机光泽而非金属镜面 | MeshPhysicalMaterial，低金属度、sheen 0.55、clearcoat 0.45。 |
| 钻石依靠切面、折射和高 IOR 形成火彩感 | 使用多面切割晶体，transmission 0.72、ior 2.1、thickness 0.35；不以发光代替结构。 |
| 产品摄影需要主光、补光与接触阴影 | 暖主光 3.2、冷补光 1.1、顶部轮廓光 1.4；仅主光投影。 |

## 尺寸与布局

每枚徽章直径 1.55、厚 0.16，符号抬高 0.05–0.28。展示采用 3×3 收藏墙：

```text
阅读       做饭       旅行
相见       合约基础   10 次铜章
50 次银章  100 次金章 白金／钻石变体
```

每个徽章中心间距 2.05，底座厚 0.12。相机初始位置 [0, 1.2, 10.8]，目标 [0, 0, 0]。单枚查看时相机平滑接近，复位回到收藏墙。

## 造型

- 阅读：打开的书与 5 页独立书页，黄铜书脊。
- 做饭：带盖锅、双耳、顶部小蒸汽形金属饰条，避免把贴纸当模型。
- 旅行：两座几何山峰与罗盘指针、定位针。
- 相见：两个互相扣合的圆环，中心一颗珍珠，不用扁平爱心图标。
- 链上系列：六边形外框、双链节、次数数字和逐枚不同的边缘刻度。

## 交互与 HUD

首屏：标题“生活徽章收藏室”、当前徽章名、材质说明、DEMO 标记。

- 拖动：旋转视角；鼠标移动：轻微视差。
- 悬停：徽章倾斜并提高轮廓光亮度。
- 点击：聚焦当前徽章；再次点击复位。
- 按钮／快捷键：上一枚 A 或 ←、下一枚 D 或 →、自动旋转 Space、复位 R。
- 编辑模式：对象、材质、合约编号、旋转速度、徽章尺寸；修改立即生效并可撤销。

## 性能预算

- 9 枚徽章、约 180 个 Mesh 以内，目标 < 300 draw calls。
- 单枚倒角分段 4、圆周分段 64；全部场景三角形 < 30 万。
- 仅 1 个主方向光投影；钻石透射仅 1 枚。
- HDRI 1k；程序化纹理 256；更新循环不创建几何、材质或纹理。

## 制作路由

Blender 已检测到。徽章需要实时生成、参数化尺寸、材质编辑、文字纹理更新和鼠标交互，且挤出倒角与 Lathe 几何以足够质量覆盖造型，因此全部主体保留在 Three.js；没有必须依赖 Blender 的有机或复杂连续曲面。环境反射使用 CC0 HDRI，其他纹理和几何全部程序化原创。
