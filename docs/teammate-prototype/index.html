HTTPS 网关把页面请求和 API 请求转发到服务器上的 Node.js 应用。应用校验演示访问凭据，写入持久化目录，并通过 RPC 连接 Monad 公共测试网。开发环境可用 npm run preview 预览这份文档。

总览

操作字段

写入接口从请求 URL 的 as 取演示身份，从 JSON 读取 action。成功时返回最新页面状态，活动操作还可返回站内活动标识 selected。失败响应含 error。

服务器保存原文与社交状态

规则全文、模拟成果与贡献文本、好友关系、待确认交易和回执汇总保存在服务器 JSON 文件。

合约保存履约和资产状态

规则摘要、执行条件、活动池余额、报名、领取状态和勋章归属由合约记录。成果摘要随领取交易提交并写入事件。

浏览器控制人物和场景

活动预览和开门在浏览器交互。人物画布与个人空间读取同一套服务器像素数据，勋章库读取已确认的勋章编号。
