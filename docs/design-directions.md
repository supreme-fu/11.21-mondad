# 五套视觉方向（均已实施）

Web 端进入 `/designs` 可预览并切换。五套主题共用业务代码、数据和权限，选择保存在当前浏览器。

## A. 生活编辑部 — 已实施，默认主题

- **气质**：像一本愿意留白的生活杂志，安静但不冷淡。
- **字体**：Fraunces + DM Sans；中文使用宋体类标题与苹方类正文。
- **颜色**：青白纸面、深墨绿正文、浅苔绿辅助面，珊瑚色只用于关键节点。
- **布局**：非对称编辑排版、细分隔线和大留白；主题以横向条目呈现，不做排行榜式卡片墙。
- **动态**：150–250ms 的状态过渡，无催促式倒计时和弹跳奖励。
- **标志细节**：两条不同节奏的路径在一个小节点交汇，表达“独立行动，行动后相遇”。
- **适用**：强调产品价值观、隐私边界与温柔感，适合比赛路演。

## B. 夜色回信 — 已实施

- **气质**：夜晚独处时收到一封没有寄件人压力的回信。
- **字体**：高对比文学宋体 + 清淡无衬线正文。
- **颜色**：完整深蓝黑暗色语义令牌、月光灰文字、暖琥珀行动点，不用紫蓝渐变。
- **布局**：延续编辑留白，以低亮度层次和暗色图形背景突出夜间阅读。
- **动态**：克制的状态过渡，支持减少动态效果。
- **标志细节**：两条微光轨迹与暖色节点在深色背景中相遇。
- **适用**：强调夜间使用、情绪沉浸和偶然交汇。

## C. 纸片行动 — 已实施

- **气质**：把心愿从冰箱贴变成真实行动，轻松、直接、有手工感。
- **字体**：圆润黑体标题 + 高可读无衬线正文。
- **颜色**：冷白底、番茄红、青草绿与分类色块，保持文本对比度。
- **布局**：错位纸片主题、粗描边、纸片阴影和更紧凑的操作区，不使用表情符号代替图标。
- **动态**：按下时有轻微纸片位移，完成不使用彩带或竞争性奖励。
- **标志细节**：描边纸片与两条不同颜色的路径在相遇处叠合。
- **适用**：更年轻、活泼的传播与线下活动场景。

## D. 奶油温柔 — 已实施

- **气质**：像一段不被催促的午后，柔软、亲近，但保持清晰的信息层级。
- **字体**：文学标题与高可读无衬线正文，保留较大行距。
- **颜色**：暖象牙背景、浅杏色行动点、可可棕正文，使用低对比阴影而非厚重边框。
- **布局**：大圆角主题卡片、柔软表单和充足留白，手机端同样保持完整内容。
- **动态**：轻微上浮与柔和阴影变化，不使用弹跳或奖励式动效。
- **标志细节**：圆角轨迹便签与浅杏色交汇节点。
- **适用**：强调温柔、陪伴感和轻松行动。

## E. 莫兰迪 — 已实施

- **气质**：收敛色彩情绪，以安静、细腻的色阶衬托真实生活。
- **字体**：文学标题与简洁正文，维持稳重阅读节奏。
- **颜色**：灰绿、灰粉、灰蓝与低饱和石灰背景，不使用高饱和大色块。
- **布局**：小圆角、细边框和交替低饱和色层，按钮与表单更加克制。
- **动态**：仅保留必要的颜色和位移反馈。
- **标志细节**：灰绿与灰粉轨迹在柔和节点相遇。
- **适用**：偏好成熟、内敛、低刺激视觉的使用者。

## 切换原则

主题由统一设计令牌和少量主题布局规则实现，不复制多份业务代码。权限、数据与 API 不受视觉切换影响。微信小程序当前采用“生活编辑部”的移动端适配，不强制同步 Web 的其他主题。
